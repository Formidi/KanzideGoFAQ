# 配信に関する取り扱い
平素より本ゲームを使用した配信、および動画をご視聴いただき、誠に感謝申し上げます。

このページでは、**配信周りの詳しい事ガイドライン、や最低限のルールなど**をまとめております。

ユーザー間でできるだけ誤解などが生まれないよう、差し支えなければ最後までご一読ください。

</br>
</br>

## 実況やゲーム内画像の転載、収益化はOK？
- 実況動画の投稿および生配信
- <span class="small">（短めの縦型動画を含む）</span>紹介動画
- 動画サイト内のサービスを使用したメンバー限定配信

など、大歓迎です！ 

収益化に関しましては、以下の項目をご覧ください。

</br>

### 投稿および配信時に遵守していただきたいこと
個人、法人問わず収益化に制限は設けていませんが、以下の点を遵守していただきますようお願いいたします。
- キャプションや概要欄といった、動画を説明する項目にタイトルおよび[ゲームのリンク](https://plicy.net/GamePlay/155561)をご記載ください。
- 本ゲームを配信したことにより何らかの損害、損失を受けた場合、一切の責任を負わないため何卒ご了承ください。

</br>
</br>

## 配信時の、おすすめのプラットフォームは？

## サムネイルにステージのイラストを使っても大丈夫？
本ゲームのイメージを著しく損なわないような表現であれば、

- 問題が出題されている画面
- ボーナスステージの画面
- クリア画面
- 『今回の問題』が表示されている画面

など、どのようなシーンでもご自由にお使いいただけます。

</br>
</br>

## BGM単品を動画で使っても大丈夫？
問題はございませんが、**ゲーム内の画像と同様に著作権を放棄しているわけではない**のでご注意ください。

使用される際は、開発者の名前(Micelle)およびXなどの連絡先を記載ください。

### 本ゲームへの誹謗について
配信に際しまして、もちろん真摯にお取り組みいただいている方も多くいらっしゃいますが、一方で**問題そのものに対して強くご不満を述べられる方が少なからず見受けられます。**

これは、本ゲームが配信企画として扱いやすい題材であり、幅広い層の配信者様に取り上げていただいていることに起因しているものと存じます。

## 配信時の注意(コメント側)

### 答えを書き込む前に…

とりわけ高難易度のレベルにおいて、**配信者が求めていないときに視聴者が解答をコメントされている**といったケースをお見掛けいたします。<span class="small">（ほかの視聴者があまりよく思わなかったり、トラブルの元となるおそれがございます）</span>

チャンネルのルール等にもよりますが、<strong class="strong large">解答する前にルールを再確認したり、配信者へ解答をしてよいか質問をする等の配慮をおこなっていただきますようお願い申し上げます。</strong>

同接の多いチャンネルに関しましてはその限りではないです。<span class="small">(収拾がつかないと思うので)</span>

</br>
</br>

### UIに迷っていたらコメントをお願いしたい

UI面の改修には努めているつもりですが、ゲーム製作は不慣れな点が多く、どうしても力が及ばない場合がございます。
たとえば配信者の使用されているPCの動作が重い場合、可能であれば **『Tips画面の右上<span class="small">(アニメの設定)</span>を押して調整できる』** という旨をコメントしていただくなど、UIに関するアドバイスを送っていただけますと幸いです。
